# Memory Ledger Pack

Made by sudal.

Memory should make future tasks safer. It is not a diary.

## Good Memory

```json
{
  "task_type": "ui",
  "mistake_type": "visual-not-verified",
  "lesson": "UI changes require browser or screenshot verification before completion.",
  "severity": "medium",
  "source": "review",
  "evidence": "Reviewer found CSS change with no rendered check."
}
```

## Bad Memory

```text
I should be more careful next time.
```

This is too vague to change behavior.

## Memory Rules

- Record repeated or high-risk patterns.
- Keep lessons short.
- Attach evidence when available.
- Promote repeated mistakes into risk brief items.
- Remove or rewrite memories that stop being useful.
