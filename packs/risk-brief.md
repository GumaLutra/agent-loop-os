# Risk Brief Pack

Made by sudal.

Use this before work starts.

## Prompt

```text
Create a short Agent Loop OS risk brief for this task.

Task type:
Task:
Relevant memories:

Return:
- Top 3-5 risks
- The cheapest useful measurement before editing
- Verification gate required before completion
```

## Good Risk Brief

```text
Risk brief:
- UI layout changes have previously been completed without rendered verification.
- The task may affect mobile and desktop differently.
- Static checks will not prove visual correctness.

Cheapest useful measurement:
- Open the page locally and inspect the changed viewport.

Verification gate:
- Browser render check plus console check before completion.
```
